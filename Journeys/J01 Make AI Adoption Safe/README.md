## J01 Make AI Adoption Safe · PUBLIC pack, release v2.1.1

The free, public layer of the J01 Journey: six questions that sit between an AI idea and a governed, evidenced use case, with the models, module cards and a private Journey Check to help you think them through for your own organisation.

### What's in the download
`J01_PUBLIC_Make_AI_Adoption_Safe.zip` (30 files)

- **Start Here** (v3.4): open this first.
- **Public Journey Guide, Deck and Summary**: the Journey in full, as slides, and on one page.
- **Risk Spine model**: the six stages on one page, with alt text.
- **Module cards** C10 to C15, and a card on how to tell whether oversight is working.
- **L0 Journey Check**: a short, private reflection you can print or type into.
- **Where to Go Next**: five neutral routes on from here.
- **Module Knowledge Editions and Reference summaries** for M10 to M15.

### Changes in v2.1.1
Start Here page 1 is clearer about where to begin and in what order. Nothing else changed from v2.1.
